# AeroMetric UA — Метеопрогноз для БПЛА 🇺🇦

Мінімалістичний, точний та швидкий погодний інформер, оптимізований для планування вильотів безпілотних апаратів:
- **FPV (до 70 м)**: приземний шар, пориви, бічний вітер, напрямок курсу.
- **Крила (300–1000 м)**: висотний вітер, висота нижнього краю хмар (LCL), ризик обледеніння.
- **Всі ешелони (до 1500 м)**: повний вертикальний зріз атмосфери.

### Джерела даних:
- **DWD ICON-EU** (основна для України 1–3 дні)
- **ECMWF IFS** (найкраща світова модель на 2–7 днів)
- **NOAA GFS** (консенсусна перевірка)
- **NOAA SWPC** (Kp-індекс геомагнітної активності)

Працює як автономний веб-додаток (PWA) на iOS, Android та ПК.
